# Transition Game

This repository contains the oTree code for the **Transition Game**, a repeated public goods game designed to study cooperation and trust in shared charging infrastructure investment for electric trucks.

In the game, four participants represent freight companies and decide how much to invest in a shared charging network over 10 rounds.

## Built with

The game was developed in Python using [oTree](https://www.otree.org/), with Visual Studio Code (VS Code) as the code editor.

## Running the game locally

1. Install Python and clone or download this repository.
2. Open the project folder in VS Code or a terminal.
3. Install the required packages:

   ```bash
   pip install -r requirements_base.txt
   ```

4. Start the local server:

   ```bash
   otree devserver
   ```

5. Open `http://localhost:8000` in your browser.
